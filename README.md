# Simple Calculator

## Project Description
A simple Python calculator that performs basic arithmetic operations.

## Technologies Used
- Python

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Handles invalid input and division by zero

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in terminal.
4. Run:
   python calculator.py
